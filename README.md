# O Circo

A ideia principal deste projeto é colocar em prática os conhecimentos adquiridos com o Tailwind CSS, explorando seus recursos e possibilidades na criação de interfaces modernas, responsivas e visualmente agradáveis.

Para isso, foi desenvolvido um site informativo sobre a história do circo, suas diferentes etapas e as transformações que ocorreram ao longo dos anos. O objetivo é apresentar, de forma visual e organizada, como o circo evoluiu desde suas origens até os dias atuais, destacando suas tradições, mudanças e características ao longo do tempo.

Durante o desenvolvimento, busquei aplicar conceitos de estruturação de páginas, estilização com Tailwind CSS, organização de elementos e adaptação do layout para diferentes tamanhos de tela, incluindo dispositivos móveis e desktops. Dessa forma, o projeto também serviu como uma oportunidade para aprimorar minhas habilidades em desenvolvimento front-end e compreender melhor a construção de páginas interativas e responsivas.

Logo abaixo, serão apresentadas algumas imagens do projeto, mostrando tanto o resultado visual das páginas quanto a maneira como elas foram construídas. A estrutura do site foi pensada de forma sequencial e interligada, com uma página direcionando o usuário para a próxima, permitindo uma navegação organizada através das diferentes fases da história do circo.

Em resumo, este projeto representa uma experiência prática de desenvolvimento, unindo aprendizado técnico, criatividade e organização visual para criar uma experiência informativa e agradável para o usuário.
